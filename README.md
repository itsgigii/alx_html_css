Headphones Page – ALX HTML/CSS Project
Project Overview

Recreate a responsive headphones landing page from Figma using HTML5 and CSS3.
The page is mobile-friendly and follows the design exactly.

Figma Design

Create a Figma account and Duplicate to Drafts.

Fonts: Source Sans Pro, Spin Cycle OT.

Max content width: 1000px, centered.

Round float values if needed.

Responsive Behavior

Switches to mobile layout when screen ≤ 480px.

Mobile-friendly navigation and stacked content.
